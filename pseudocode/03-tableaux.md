## Exo 1

```text
Algorithme pour détecter la plus grande valeur d'un tableau de nombres sans Math.max()

Variables
i : NUMBER
tab[] : NUMBER
maximum : NUMBER

INIT
    LIRE tab[]
START
    let maximum = tab[0]
    DEBUT FUNCTION maximum (tab[])
        POUR i de 0 à tab[].length par pas de 1 FAIRE
            SI tab[i] > maximum ALORS
                maximum = tab[i]
            FIN SI
        FIN POUR
        RETURN maximum
    FIN FUNCTION
FIN
```
