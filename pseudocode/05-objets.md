# Pseudocode chapitre 05-objets

## Exo 1

```text
Algorithme pour retourner un nom complet à partir d'un {OBJET}

Variables
personne : {OBJET}
resultat : STR

INIT
    LIRE personne
START
    DEBUT FUNCTION fullName (personne)
        resultat <- personne.prenom + " " + personne.nom
        RETURN resultat
    FIN FUNCTION
FIN
```

## Exo 2

```text
Algorithme pour retourner des noms complets à partir d'un [{OBJETS}], comparés à un critère d'âge minimum

Variables
personnes : [{OBJETS}]
ageMin : NUMBER


INIT
    LIRE personnes
START
    DEBUT FUNCTION filtrerParAge (personnes, ageMin)
        RETURN personnes FILTRE par [personne] dont AGE personne >= ageMin 
    FIN FUNCTION
FIN
```
