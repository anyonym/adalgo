# Pseudocode chapitre 02-boucles

## Exo 1

```text
Algorithme pour afficher tous les nombres d'une suite d'itérations

Variables
n : NUMBER
i : NUMBER
nombres : STR

INIT
    LIRE n
START
    DEBUT FUNCTION compterJusqua (n) :
        let nombres <- ""
        POUR i = 1, TANT QUE i <= n, i++
            let nombre = str(i) + ", "
            SI (i = n) ALORS
                nombres += str(i)
            SINON
                nombres += nombre
            FIN SI
        FIN POUR
        AFFICHER nombres
    FIN FUNCTION
FIN
```

## Exo 2

```text
Algorithme pour afficher uniquement les nombres pairs

Variables
n : NUMBER
i : NUMBER
nombres : STR

INIT
    LIRE n
START
    DEBUT FUNCTION afficherPairs (n) :
        let nombres <- ""

                nombres += str(i)
            SINON
                nombres += nombre
            FIN SI
        FIN POUR
        AFFICHER nombres
    FIN FUNCTION
FIN
```
